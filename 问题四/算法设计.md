# 问题 4 核心算法设计说明

> 本说明与 `C题_问题4_RK4_NSGA2.py` 中的函数定义保持一致，用于论文“算法设计”章节。核心算法采用“NSGA-II 外层优化 + 二分搜索最大服务器数 + RK4 全年逐时传热仿真”的嵌套结构。

## 1. 算法层次

### 1.1 总体调用关系

```text
NSGA-II 多目标优化
  `-- _evaluate_chrom              个体评价：材料/深度/壁厚 -> 目标与约束
        `-- bisect_max_N           二分搜索当前方案的最大可放服务器数 N
              `-- max_N_feasible   判断给定 N 是否满足全年温度约束
                    `-- simulate_year  全年 8760 h 逐时传热仿真
                          `-- rk4_integrate_step  单个 RK4 积分步
                                `-- heat_balance_rhs  传热方程右端项
                                      `-- _conductance  逐时换热与散热能力计算
```

### 1.2 层次说明

| 层次 | 函数 | 作用 |
| --- | --- | --- |
| 最内层 | `_conductance` | 计算任意温度、任意小时刻的换热系数与散热量 |
| 内层 | `heat_balance_rhs`、`rk4_integrate_step` | 建立传热 ODE 并完成单步 RK4 积分 |
| 模型层 | `simulate_year` | 求解全年逐时温度与散热过程，输出统计指标 |
| 可行性层 | `max_N_feasible`、`bisect_max_N` | 在给定材料/深度/壁厚下搜索最大可放服务器数 |
| 优化层 | `_evaluate_chrom`、`nsga2` | 对设计变量进行多目标优化并生成 Pareto 前沿 |
| 稳态校核层 | `steady_capacity` | 用稳态热阻模型快速估计单点散热能力与 N 上限 |

## 2. 核心函数说明

### 2.1 `steady_capacity`

**函数签名**

```python
def steady_capacity(cfg, t_inf, u_mean=0.0, props_at=None,
                    props_arrays=None, max_iter=5, tol=1e-4) -> dict
```

**输入**

- `cfg`：结构几何与材料配置字典，包含 `geom`、`k_wall`、`cost` 等。
- `t_inf`：海水温度，单位 °C。
- `u_mean`：平均来流速度，单位 m/s，默认 0。
- `props_at`：海水物性插值函数。
- `props_arrays`：可选的物性数组版本。
- `max_iter`：壁温迭代最大次数。
- `tol`：壁温收敛容差。

**输出**

| 字段 | 含义 |
| --- | --- |
| `h_air` | 舱内自然对流换热系数，W/(m^2·K) |
| `h_sea` | 舱外海水对流换热系数，W/(m^2·K) |
| `h_total` | 总换热系数，W/(m^2·K) |
| `Q` | 稳态极限散热量，W |
| `N` | 按稳态散热量估算的可放服务器数 |
| `N_space` | 由舱内容积确定的空间上限 |
| `T_wi`、`T_wo` | 内壁、外壁温度，°C |

**算法要点**

通过内外壁温迭代求解热阻链：

```text
R_total = R_air + R_wall + R_sea
Q = (T_MAX - t_inf) / R_total
```

海水侧换热系数采用自然对流与强制对流的混合模型：

```text
h_sea = (h_nat^3 + h_forced^3)^(1/3)
```

该函数用于二分搜索前的稳态上限估计和月度校核。

### 2.2 `_conductance`

**函数签名**

```python
def _conductance(cfg, T, hourf, env, props_at) -> dict
```

**输入**

- `cfg`：结构几何与材料配置字典。
- `T`：当前壳体温，°C。
- `hourf`：当前小时数，可为小数，用于 RK4 中间节点插值。
- `env`：全年环境字典，包含 `T_inf`、`U`、`h_forced`、`d_eff`、`hn_grid`。
- `props_at`：海水物性插值函数。

**输出**

| 字段 | 含义 |
| --- | --- |
| `Q` | 当前状态下的实际散热量，W |
| `h_air`、`h_nat`、`h_forced`、`h_mixed` | 各换热系数，W/(m^2·K) |
| `Q_cap` | 按壳温上限计算的极限散热能力，W |
| `Gr_Re2` | Gr/Re^2 比值，用于流态判别 |
| `regime` | 流态：自然对流主导 / 强制对流主导 / 混合对流 |
| `T_inf`、`T_wo`、`U` | 当前环境海温、外壁温、流速 |

**算法要点**

1. 对 `T_inf`、`U`、`h_forced` 做线性插值，支持 RK4 半时间节点。
2. 通过两次壁温迭代求解外壁温 `T_wo`。
3. 根据 `Gr/Re^2` 判别流态，并输出对应混合换热系数。

### 2.3 `heat_balance_rhs`

**函数签名**

```python
def heat_balance_rhs(cfg, N, mcp, T, hourf, env, props_at) -> tuple[float, dict]
```

**输入**

- `cfg`：结构几何与材料配置字典。
- `N`：服务器数量。
- `mcp`：壳体的热容 `m·c_p`，J/K。
- `T`：当前壳体温，°C。
- `hourf`：当前小时数。
- `env`：全年环境字典。
- `props_at`：海水物性插值函数。

**输出**

- `dT/dt`：传热微分方程右端项，°C/h。
- 第二个返回值：`_conductance` 返回的换热结果字典。

**算法要点**

传热微分方程为：

```text
m·c_p · dT/dt = N·Q0 - Q_sea(t, T)
```

其中 `Q_sea` 由 `_conductance` 给出，`Q0` 为单台服务器发热功率。

### 2.4 `rk4_integrate_step`

**函数签名**

```python
def rk4_integrate_step(cfg, N, mcp, T, hourf, dt, env, props_at) -> tuple[float, dict, float]
```

**输入**

- `cfg`、`N`、`mcp`、`T`、`hourf`：同 `heat_balance_rhs`。
- `dt`：积分步长，默认为 3600 s。
- `env`：全年环境字典。
- `props_at`：海水物性插值函数。

**输出**

- `T_new`：本步积分后的新壳体温，°C。
- 第二个返回值：步末换热结果字典。
- `Q_eff`：RK4 等效散热量，W。

**算法要点**

采用四阶 Runge-Kutta：

```text
k1 = f(T, t)
k2 = f(T + 0.5·dt·k1, t + 0.5)
k3 = f(T + 0.5·dt·k2, t + 0.5)
k4 = f(T + dt·k3, t + 1)
T_new = T + dt·(k1 + 2·k2 + 2·k3 + k4) / 6
```

`Q_eff` 为四个节点散热量按 RK4 权重得到的等效值。

### 2.5 `simulate_year`

**函数签名**

```python
def simulate_year(cfg, N, env, props_at, dt=3600.0,
                  warmup_h=168, progress_label="", T0=None) -> dict
```

**输入**

- `cfg`：结构几何与材料配置字典。
- `N`：服务器数量。
- `env`：全年环境字典，长度 8760。
- `props_at`：海水物性插值函数。
- `dt`：积分步长，s。
- `warmup_h`：丢弃的初始瞬态小时数，默认 168。
- `progress_label`：进度显示标签。
- `T0`：可选初始壳温，默认由稳态估算给出。

**输出**

| 字段 | 含义 |
| --- | --- |
| `T_max`、`T_mean` | 全年最高、平均壳温，°C |
| `Q_mean`、`Q_min`、`Q_max` | 全年散热统计，W |
| `Q_fluct_pct` | 散热波动百分比 |
| `Q_cap_mean/min/max` | 极限散热能力统计，W |
| `T_arr`、`Q_arr`、`Q_eff_arr` | 逐时温度、散热量、等效散热量数组 |
| `h_mix_arr`、`h_nat_arr`、`h_forced_arr` | 逐时换热系数数组 |
| `regime_cnt` | 三种流态小时数统计 |
| `gr_re2_arr`、`t_wo_arr` | 逐时 Gr/Re^2 与外壁温数组 |
| `worst_idx` | 最高壳温对应小时索引 |
| `N`、`ok` | 服务器数、仿真是否成功 |

**算法要点**

1. 初始化壳温。
2. 对 8760 h 逐小时调用 `rk4_integrate_step`。
3. 丢弃前 `warmup_h` 小时，消除初值瞬态影响。
4. 输出全年统计指标，供可行性判断和目标函数计算使用。

### 2.6 `max_N_feasible`

**函数签名**

```python
def max_N_feasible(N, cfg, env, props_at, q_opt, cache) -> bool
```

**输入**

- `N`：待判断的服务器数量。
- `cfg`：结构几何与材料配置字典。
- `env`：全年环境字典。
- `props_at`：海水物性插值函数。
- `q_opt`：乐观稳态散热上限，W。
- `cache`：已仿真的 `N -> 结果字典` 缓存。

**输出**

- `True`：方案可行，全年最高壳温不超过 `T_MAX`。
- `False`：方案不可行。

**算法要点**

先利用热平衡上限快速剪枝：

```text
若 N·Q0 > q_opt·1.001，直接判为不可行
```

否则调用 `simulate_year` 并检查：

```text
T_max <= T_MAX + 1e-9
```

### 2.7 `bisect_max_N`

**函数签名**

```python
def bisect_max_N(cfg, env, props_at, max_iter=10) -> tuple[dict, int]
```

**输入**

- `cfg`：结构几何与材料配置字典。
- `env`：全年环境字典。
- `props_at`：海水物性插值函数。
- `max_iter`：二分最大迭代次数。

**输出**

- 第一个返回值：`N_max` 对应的全年仿真结果字典。
- 第二个返回值：最大可放服务器数 `N_max`。

**算法要点**

1. 用平均海温、平均流速的稳态模型估计二分上界。
2. 用最高海温、最大流速的乐观散热量做快速不可行剪枝。
3. 利用“N 越大全年最高壳温越高”的单调性进行二分。
4. 对每个测试点调用 `max_N_feasible`，结果写入缓存避免重复仿真。

### 2.8 `_evaluate_chrom`

**函数签名**

```python
def _evaluate_chrom(chrom, ctx) -> dict
```

**输入**

- `chrom`：设计变量列表 `[材料索引, 深度 m, 壁厚 m]`。
- `ctx`：上下文字典，包含材料表、环境数据、物性、潮汐数据等。

**输出**

| 字段 | 含义 |
| --- | --- |
| `feasible` | 是否满足全部约束 |
| `viol` | 总约束违反量 |
| `obj` | 目标向量 `[-Q_mean, cost, -life]` |
| `res` | 个体结果字典，含 N、Q、成本、寿命、约束余量等 |

**算法要点**

1. 由 `chrom` 构建配置 `cfg`。
2. 计算水压、寿命、最小壁厚等约束。
3. 对深度做环境缓存，避免重复构建全年环境。
4. 调用 `bisect_max_N` 求最大 N 和全年性能。
5. 汇总约束违反量与目标向量。

### 2.9 `nsga2`

**函数签名**

```python
def nsga2(ctx, pop_size=NSGA_POP, generations=NSGA_GEN,
          seed=NSGA_SEED, workers=1) -> tuple[list, list, list]
```

**输入**

- `ctx`：上下文字典。
- `pop_size`：种群规模。
- `generations`：进化代数。
- `seed`：随机数种子。
- `workers`：并行 worker 数。

**输出**

- `pop`：最终种群，元素为 `Individual`。
- `pareto`：可行 Pareto 前沿个体结果列表。
- `history`：每代进化统计 `(代数, 前沿个体数, 最大 Q_mean, 平均成本)`。

**算法要点**

1. 初始化种群，调用 `_evaluate_chrom` 完成个体评价。
2. 使用 `fast_non_dominated_sort` 分层。
3. 使用 `crowding_distance` 保持前沿多样性。
4. 锦标赛选择 + SBX 交叉 + 多项式变异生成子代。
5. 父子合并后按非支配层和拥挤距离选择下一代。

### 2.10 NSGA-II 算子

| 函数 | 输入 | 输出 | 算法要点 |
| --- | --- | --- | --- |
| `dominates` | 两个 `Individual`，容差 | 布尔值 | 先比较可行性，再按目标向量比较支配关系 |
| `fast_non_dominated_sort` | 种群列表 | 非支配层索引列表 | 按被支配次数分层 |
| `crowding_distance` | 种群、某一层索引 | 无返回值 | 直接修改个体的 `crowd` 属性 |
| `tournament` | 种群、随机数生成器 | 优胜个体 | 二元锦标赛，比较 rank 与 crowding distance |
| `sbx` | 两个父代值、边界、随机数生成器 | 两个子代值 | 模拟二进制交叉 |
| `poly_mut` | 一个值、边界、随机数生成器 | 变异后的值 | 多项式变异 |
