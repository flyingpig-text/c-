# 问题 1 核心算法设计（函数级说明）

> 对应代码：[C题_问题1_核心算法.py](C题_问题1_核心算法.py)
> 用途：论文“算法设计”章节素材。主脚本《C题_问题1_服务器散热_整数模型.py》未被修改。

## 一、总体流程

问题 1 为退化整数规划，按以下 5 步依次计算，最终容量取两个上限的最小值后向下取整：

1. 圆柱外表面积：$A=\pi DL$
2. 自然对流 Nu 关联式：求解换热系数 $h$
3. 最大总散热量与理论上限：$Q_{\max}=hA\Delta T$，$N_{\text{theory}}=Q_{\max}/q_0$
4. 空间上限：$N_{\text{space}}=V_{\text{inner}}/V_{\text{server}}$
5. 最终容量：$N=\lfloor\min(N_{\text{theory}},N_{\text{space}})\rfloor$，当 $N_{\text{theory}}<1$ 时输出 $0$

函数调用关系：

```
solve_q1
 ├─ compute_areas                （步骤 1）
 ├─ solve_heat_transfer          （步骤 2）
 │   ├─ h_horizontal_cylinder    （自然对流关联式）
 │   │   ├─ air_props            （空气物性）
 │   │   └─ sea_props            （海水物性）
 ├─ compute_thermal_capacity     （步骤 3）
 ├─ compute_spatial_capacity     （步骤 4）
 └─ compute_final_capacity       （步骤 5）
```

## 二、函数输入输出说明

### 1. `compute_areas(D_outer, L_outer, wall)`

- 算法步骤：步骤 1，几何面积计算。
- 输入：
  - `D_outer`：`float`，外轮廓直径，m
  - `L_outer`：`float`，外轮廓长度，m
  - `wall`：`float`，外壳壁厚，m（交付清单未给，问题 1 基准按薄壳 w=0）
- 输出（`dict[str, float]`）：
  - `D_inner`：内部直径，m
  - `L_inner`：内部可用长度，m
  - `A_cyl`：圆柱侧表面积 $A=\pi DL$，m²
  - `A_out`：完整外表面积（含两端），m²
  - `A_in`：完整内表面积，m²
- 关键公式：
  - $D_{\text{inner}}=D_{\text{outer}}-2w$
  - $L_{\text{inner}}=L_{\text{outer}}-2w$
  - $A_{\text{cyl}}=\pi D_{\text{outer}}L_{\text{outer}}$
  - $A_{\text{out}}=A_{\text{cyl}}+2(\pi D_{\text{outer}}^2/4)$

### 2. `solve_heat_transfer(D_outer, L_outer, D_inner, L_inner, A_out, A_in, k_wall, wall, t_air_max, t_sea, max_iter=60, tol=1e-6)`

- 算法步骤：步骤 2，自然对流换热系数求解；热阻串联 + 壁温自洽迭代。
- 输入：
  - `D_outer`、`L_outer`：外轮廓直径、长度，m
  - `D_inner`、`L_inner`：内部直径、长度，m
  - `A_out`、`A_in`：外、内换热面积，m²
  - `k_wall`：壁面导热系数，W/(m·K)
  - `wall`：壁厚，m（问题 1 基准取 0，壁厚影响在灵敏度中单独分析）
  - `t_air_max`：服务器允许最高温度，℃
  - `t_sea`：海水温度，℃
  - `max_iter`：最大迭代次数，默认 60
  - `tol`：收敛容差，默认 1e-6
- 输出（`dict[str, float]`）：
  - `h_air`：舱内空气自然对流换热系数，W/(m²·K)
  - `h_sea`：海水自然对流换热系数，W/(m²·K)
  - `h_total`：以外表面为参考的综合换热系数，W/(m²·K)
  - `t_wi`：内壁温，℃
  - `t_wo`：外壁温，℃
  - `r_total`：总热阻，K/W
  - `q_total`：迭代收敛时的散热量，W
- 关键公式（Churchill-Chu 关联式）：
  - $\mathrm{Pr}=\nu/\alpha$
  - $\mathrm{Ra}=g\beta\Delta TD^3/(\nu\alpha)$
  - $\mathrm{Nu}=\left[0.60+\dfrac{0.387\mathrm{Ra}^{1/6}}{(1+(0.559/\mathrm{Pr})^{9/16})^{8/27}}\right]^2$
  - $h=\mathrm{Nu}\,k/D$
  - 热阻串联：$R_{\text{total}}=R_{\text{air}}+R_{\text{wall}}+R_{\text{sea}}$
  - 壁温更新：$T_{wi}=T_{\text{air,max}}-QR_{\text{air}}$，$T_{wo}=T_{\text{sea}}+QR_{\text{sea}}$
  - 综合换热系数：$h_{\text{total}}=1/(R_{\text{total}}A_{\text{out}})$

### 3. `compute_thermal_capacity(h_total, a_eff, t_air_max, t_sea, q0)`

- 算法步骤：步骤 3，散热理论上限。
- 输入：
  - `h_total`：综合换热系数，W/(m²·K)
  - `a_eff`：有效总散热面积，m²
  - `t_air_max`：允许最高温度，℃
  - `t_sea`：海水温度，℃
  - `q0`：单台服务器产热，W
- 输出（`dict[str, float]`）：
  - `q_max`：最大总散热量，W
  - `n_theory`：散热理论上限，台
- 关键公式：
  - $Q_{\max}=h_{\text{total}}A_{\text{eff}}(T_{\max}-T_\infty)$
  - $N_{\text{theory}}=Q_{\max}/q_0$

### 4. `compute_spatial_capacity(D_inner, L_inner, w_server, h_server, l_server)`

- 算法步骤：步骤 4，空间上限。
- 输入：
  - `D_inner`、`L_inner`：内部直径、长度，m
  - `w_server`、`h_server`、`l_server`：单台服务器宽、高、长，m
- 输出（`dict[str, float]`）：
  - `v_inner`：舱内部可用容积，m³
  - `v_server`：单台服务器体积，m³
  - `n_space`：空间上限，台
- 关键公式：
  - $V_{\text{inner}}=\pi D_{\text{inner}}^2L_{\text{inner}}/4$
  - $V_{\text{server}}=w_{\text{server}}h_{\text{server}}l_{\text{server}}$
  - $N_{\text{space}}=V_{\text{inner}}/V_{\text{server}}$

### 5. `compute_final_capacity(n_theory, n_space)`

- 算法步骤：步骤 5，退化整数规划取整。
- 输入：
  - `n_theory`：散热理论上限，台
  - `n_space`：空间上限，台
- 输出（`dict[str, int]`）：
  - `n`：最终可容纳服务器台数，整数
- 关键逻辑：
  - $N=\lfloor\min(N_{\text{theory}},N_{\text{space}})\rfloor$
  - 异常判定：若 $N_{\text{theory}}<1$，输出 $N=0$

### 6. `solve_q1(...)`

- 算法步骤：主流程，按顺序调用步骤 1-5。
- 输入（均有默认值，对应题目基准工况）：
  - `D_outer=1.0`，`L_outer=12.0`，`wall=0.01`，单位 m
  - `k_wall=None`：缺省时自动从数据包解析 304 不锈钢导热系数 14.4 W/(m·K)
  - `t_air_max=80.0`，`t_sea=20.0`，单位 ℃
  - `q0=500.0`，W
  - `w_server=0.4826`，`h_server=0.04445`，`l_server=0.525`，单位 m
- 输出（`dict`）：合并以上各函数的全部输出键，另加 `k_wall`。
