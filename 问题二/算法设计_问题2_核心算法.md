# 问题 2 核心算法设计（函数级说明）

> 对应代码：[C题_问题2_核心算法.py](C题_问题2_核心算法.py)
> 用途：论文“算法设计”章节素材。主脚本《C题_问题2_枚举shape_GA_SLSQP.py》
> 通过 `import` 调用本模块，GA/SLSQP 优化与云图绘制仍保留在主脚本中。

## 一、总体流程

问题 2 在 $1\text{ m}\times 1\text{ m}\times 12\text{ m}$ 外形约束内，
枚举圆柱 / 长方体两种外壳并设计纵向矩形翅片，目标是最大化可容纳服务器台数 $N$。
核心算法按以下 5 步计算一组翅片参数 $(N_f, H_f, d_f)$ 对应的容量：

1. 翅片 / 基体几何：
   $A_{\text{fin}}=(2H_f+d_f)L$（单根，含两侧与翅尖），
   $A_{\text{base}}=A_{\text{侧}}+A_{\text{端}}-N_f d_f L$，
   $A_{\text{eff}}=A_{\text{base}}+\eta_f N_f A_{\text{fin}}$
2. 热阻网络（与问题 1 统一口径，壁温自洽迭代）：
   $R_{\text{total}}=1/(h_{\text{air}}A_{\text{in}})+R_{\text{wall}}+1/(h_{\text{sea}}A_{\text{eff}})$
3. 最大散热量与理论上限（统一口径，与问题 1 一致）：
   $Q_{\max}=h_{\text{total}}A_{\text{eff}}(T_{\max}-T_\infty)$，
   等价于 $Q_{\max}=(T_{\max}-T_\infty)/R_{\text{total}}$；
   $N_{\text{theory}}=Q_{\max}/q_0$
4. 空间上限（体积法上界）：
   $N_{\text{space}}=V_{\text{inner}}/V_{\text{server}}$
5. 最终容量：
   $N=\lfloor\min(N_{\text{theory}},N_{\text{space}})\rfloor$，
   当 $N_{\text{theory}}<1$ 时输出 $0$

函数调用关系：

```text
solve_q2 / evaluate_design
 ├─ _build_geometry            （基体与翅片几何）
 │   └─ _char_len              （特征长度：圆柱直径 / 方柱等面积当量直径）
 ├─ _solve_fin_and_network     （eta_f 与热阻网络固定点迭代）
 │   ├─ _fin_efficiency        （翅片效率）
 │   └─ _solve_thermal_network （热阻网络 + 壁温迭代）
 │       ├─ _inner_geometry    （内腔尺寸 / 内壁面积 / 内腔体积）
 │       ├─ _wall_resistance   （壳体导热热阻）
 │       ├─ h_horizontal_cylinder（Churchill-Chu 自然对流）
 │       │   ├─ air_props      （舱内空气物性）
 │       │   └─ sea_props      （海水物性）
 │       └─ _ra_number         （Ra 适用域检查）
 └─ _raw_metrics               （无可行性门禁的连续指标，供 SLSQP 梯度）
```

## 二、输入输出说明

### 1. `_build_geometry(shape, Hf)`

- 算法步骤：步骤 1，由翅高反推基体尺寸，翅尖刚好贴住 $1\text{ m}$ 外形约束。
- 输入：
  - `shape`：`str`，`"cylinder"`（圆柱）或 `"cuboid"`（长方体）
  - `Hf`：`float`，翅高，m
- 输出（`dict`）：
  - `char_len`：Churchill-Chu 特征长度，m（圆柱=基体直径；长方体=等面积当量直径 $2a/\sqrt{\pi}$）
  - `base_side`：基体直径或边长 $D_{\text{base}}=1-2H_f$，m
  - `base_side_area`：基体侧面积，m²（圆柱 $\pi DL$；长方体 $4aL$）
  - `base_end_area`：两端封头面积，m²
  - `fin_banks`：翅片圈/面数（圆柱 1，长方体 4）
  - `perimeter`：根部周长，m
  - `overlap_limit`：翅根可布置长度，m（圆柱 $\pi D$；长方体每面边长 $a$）
  - `v_cross`：基体横截面积，m²
- 关键公式：$D_{\text{base}}=1-2H_f$，$a_{\text{base}}=1-2H_f$，
  等面积当量直径 $D_{\text{eq}}=2a/\sqrt{\pi}$。

### 2. `_char_len(shape, base_side)`

- 输入：`shape` 外形；`base_side` 基体直径或边长，m。
- 输出：`float`，Churchill-Chu 特征长度，m。
- 逻辑：圆柱直接返回直径；长方体返回 $2a/\sqrt{\pi}$，避免把方柱边长
  直接当作圆柱直径导致换热系数系统性高估。

### 3. `air_props(T)` / `sea_props(T)`

- 输入：`T` 摄氏温度，℃。
- 输出（`dict[str, float]`）：`rho`（密度，kg/m³）、`cp`（比热容，J/(kg·K)）、
  `k`（导热系数，W/(m·K)）、`mu`（动力粘度，Pa·s）、`beta`（体膨胀系数，1/K）。
- 说明：与问题 1 核心算法保持同一套近似式；海水按 $S=35‰$。

### 4. `h_horizontal_cylinder(D, dT, T_film, props_fn=sea_props)`

- 算法步骤：步骤 2，自然对流换热系数。
- 输入：
  - `D`：特征长度，m
  - `dT`：壁面与流体温差，℃
  - `T_film`：膜温，℃
  - `props_fn`：物性函数，默认 `sea_props`，舱内空气传 `air_props`
- 输出：`float`，换热系数 $h$，W/(m²·K)。
- 关键公式（Churchill-Chu）：
  - $\mathrm{Pr}=\nu/\alpha$
  - $\mathrm{Ra}=g\beta\Delta T D^3/(\nu\alpha)$
  - $\mathrm{Nu}=\left[0.60+\dfrac{0.387\mathrm{Ra}^{1/6}}
    {(1+(0.559/\mathrm{Pr})^{9/16})^{8/27}}\right]^2$
  - $h=\mathrm{Nu}\,k/D$

### 5. `_load_k_wall()` / `_k_wall()`

- 输入：无。
- 输出：`float`，壳体材料（304 不锈钢）20 ℃ 导热系数，W/(m·K)。
- 说明：优先从 `C题数据/清洗后数据/金属导热系数_EngineeringToolbox_clean.csv`
  读取；数据缺失时回退工程默认值 14.4。`_k_wall()` 带缓存，GA/SLSQP 多次
  调用只读一次文件。

### 6. `_inner_geometry(shape, geo)`

- 算法步骤：步骤 4 的前置几何计算。
- 输入：`shape` 外形；`geo` 为 `_build_geometry` 的输出。
- 输出（`dict[str, float]`）：
  - `inner_side`：内部直径 / 内边长 $D_{\text{inner}}=D_{\text{base}}-2w$，m
  - `inner_len`：内部长度 $L_{\text{inner}}=L-2w$，m
  - `a_in`：完整内壁换热面积（含两端封头），m²
  - `v_inner`：内部可用容积，m³
- 关键公式：
  - 圆柱：$A_{\text{in}}=\pi D_{\text{inner}}L_{\text{inner}}+2(\pi D_{\text{inner}}^2/4)$，
    $V_{\text{inner}}=\pi D_{\text{inner}}^2 L_{\text{inner}}/4$
  - 长方体：$A_{\text{in}}=4a_{\text{inner}}L_{\text{inner}}+2a_{\text{inner}}^2$，
    $V_{\text{inner}}=a_{\text{inner}}^2 L_{\text{inner}}$

### 7. `_wall_resistance(shape, geo, inner, k_wall)`

- 算法步骤：步骤 2，壳体壁导热热阻。
- 输入：`shape`、`geo`、`inner`（`_inner_geometry` 输出）、`k_wall`。
- 输出：`float`，壁导热热阻 $R_{\text{wall}}$，K/W。
- 关键公式：
  - 圆柱侧壁：$R=\ln(D_{\text{base}}/D_{\text{inner}})/(2\pi kL)$，
    两端封头：$R=2w/(k\pi D_{\text{inner}}^2/4)$
  - 长方体按平板近似：$R=w/(kA_m)$，$A_m$ 取内外侧面积平均值，
    两端封头：$R=2w/(ka_{\text{inner}}^2)$

### 8. `_solve_thermal_network(shape, geo, a_eff, k_wall, ...)`

- 算法步骤：步骤 2，热阻网络 + 壁温自洽迭代。
- 输入：`shape`、`geo`、`a_eff`（含翅片有效外面积，m²）、`k_wall`；
  可选 `t_air_max=80`、`t_sea=20`、`max_iter=60`、`tol=1e-6`。
- 输出（`dict[str, float]`，内腔非法时返回 `None`）：
  - `h_air`：舱内空气自然对流换热系数，W/(m²·K)
  - `h_sea`：海侧自然对流换热系数，W/(m²·K)
  - `h_total`：以外面积 $A_{\text{eff}}$ 为参考的综合换热系数，W/(m²·K)
  - `t_wi` / `t_wo`：内壁温 / 外壁温，℃
  - `r_total`：总热阻，K/W
  - `q_total`：热阻网络迭代散热量，W（与统一口径 Q_max 等价，
    浮点精度内一致，仅作为网络求解的中间量）
  - `v_inner`、`a_in`、`inner_side`、`inner_len`：内腔中间量
  - `ra_inner` / `ra_outer`：舱内 / 海侧瑞利数（适用域检查）
  - `converged`：壁温迭代是否收敛，`bool`
- 关键公式：
  - $R_{\text{total}}=1/(h_{\text{air}}A_{\text{in}})+R_{\text{wall}}+1/(h_{\text{sea}}A_{\text{eff}})$
  - $Q=(T_{\max}-T_\infty)/R_{\text{total}}$
  - $T_{\text{wi}}=T_{\max}-QR_{\text{air}}$，
    $T_{\text{wo}}=T_\infty+QR_{\text{sea}}$
  - $h_{\text{total}}=1/(R_{\text{total}}A_{\text{eff}})$

### 9. `_fin_efficiency(h_sea, Hf, df)`

- 算法步骤：步骤 1，翅片效率。
- 输入：`h_sea` 海侧换热系数，W/(m²·K)；`Hf` 翅高，m；`df` 翅厚，m。
- 输出：`float`，翅片效率 $\eta_f\in(0,1]$。
- 关键公式（绝热翅尖直矩形翅）：
  $m=\sqrt{2h/(k_f d_f)}$，$\eta_f=\tanh(mH_f)/(mH_f)$。

### 10. `_solve_fin_and_network(shape, geo, nf, Hf, df, k_wall)`

- 算法步骤：步骤 1-2 的耦合求解。$A_{\text{eff}}$ 依赖 $\eta_f$，
  $\eta_f$ 依赖 $h_{\text{sea}}$，而 $h_{\text{sea}}$ 依赖壁温，故做固定点迭代。
- 输入：`shape`、`geo`、`nf`（每面/每圈翅片数）、`Hf`、`df`、`k_wall`。
- 输出（`dict`）：`eta_f`、`a_fin_one`、`total_fins`、`a_base`、`a_eff`，
  以及 `net`（`_solve_thermal_network` 的输出）。

### 11. `_raw_metrics(shape, nf, Hf, df)`

- 用途：供 SLSQP 数值梯度使用，不施加可行性门禁，始终返回连续值。
- 输入：`shape`、`nf`、`Hf`、`df`。
- 输出（`dict`，几何/内腔非法时返回 `None`）：`geo`、`base_side`、
  `h`（=海侧 `h_sea`）、`h_air`、`h_total`、`t_wi`、`t_wo`、`r_total`、
  `q_max`（= $h_{\text{total}}A_{\text{eff}}\Delta T$）、`eta_f`、`a_fin_one`、
  `a_base`、`a_eff`、`n_theory`、`n_space`、
  `v_inner`、`ra_inner`、`ra_outer`、`converged`。

### 12. `evaluate_design(shape, nf, Hf, df, collect_warnings=True)`

- 算法步骤：核心算法总入口（含可行性门禁），供 GA、自检与绘图调用。
- 输入：
  - `shape`：`"cylinder"` 或 `"cuboid"`
  - `nf`：翅片数（长方体=每个侧面的数量）
  - `Hf`：翅高，m
  - `df`：翅厚，m
  - `collect_warnings`：是否收集警告，默认 `True`
- 输出（`dict`）：
  - `feasible`：是否可行，`bool`
  - `shape`、`nf`、`Hf`、`df`、`base_side`：设计参数
  - `h`（海侧 `h_sea`）、`h_air`、`h_total`：换热系数，W/(m²·K)
  - `t_wi`、`t_wo`：壁温，℃
  - `eta_f`：翅片效率；`a_fin_one`：单翅面积，m²
  - `a_base`、`a_eff`：基体 / 有效散热面积，m²
  - `q_max`：最大散热量 $Q_{\max}=h_{\text{total}}A_{\text{eff}}\Delta T$，W
  - `n_theory`：散热理论上限，台；`n_space`：空间上限，台；`N`：最终台数，整数
  - `v_inner`、`r_total`、`ra_inner`、`ra_outer`、`converged`：中间量与检查项
  - `warnings`：中文警告列表（几何、Ra 适用域、迭代收敛等）
- 鲁棒性：任何不满足几何 / 空间 / 一维翅片假设的输入都返回
  `feasible=False` 与警告，不抛异常。
- 输入合法性检查项：`nf∈[NF_MIN, NF_MAX]`（整数）、`Hf/df` 在声明区间内、
  `Hf/df≥3`（一维直翅假设）、翅根不重叠（`nf·df≤可布置周长`）、
  内腔尺寸非负；任一不满足即返回 `feasible=False`。

### 13. `solve_q2(shape, nf, Hf, df)`

- 算法步骤：问题 2 核心算法总入口，等价于 `evaluate_design`。
- 输入 / 输出：同 `evaluate_design`。

## 三、与问题 1 的一致性

裸圆柱 $D=1\text{ m}$、$L=12\text{ m}$、无翅片时，本模块的热阻网络
应精确复现问题 1 基准算例：

| 指标                  |        问题 1 基准 |    问题 2 核心模块回归 |
| ------------------- | -------------: | -------------: |
| $h_{\text{sea}}$    | 210.5 W/(m²·K) | 210.5 W/(m²·K) |
| Q_max               |       7761.5 W |       7761.5 W |
| $N_{\text{theory}}$ |        15.52 台 |        15.52 台 |
| $N_{\text{space}}$  |       802.38 台 |       802.38 台 |
| $N$                 |           15 台 |           15 台 |
