## 3. 使用方法（问题 3 脚本）

可把 `SAFETY_FACTOR=2.5` 改为按 GB/T 150.1-2024 的
`屈服强度/1.5`（或抗拉强度/2.7）计算许用应力；
材料价格与腐蚀速率可从上述清洗 CSV 读取，替换脚本中
`build_material_table()` 的工程默认值。

## 4. 注意

- 上海金属网期货价为“主力合约”参考价，不是成品板/管挂牌价；
- 价格、腐蚀速率会随市场与暴露条件变化，论文引用时需注明下载日期；
- 钛合金（TC4）在以上公开数据中未检索到统一均匀腐蚀速率数值，
  建议按附件“腐蚀类型：None”并结合标准手册给出保守值。
