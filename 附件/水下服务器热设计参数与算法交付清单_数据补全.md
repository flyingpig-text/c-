#### 3.6 设计使用寿命基准

已定默认（脚本与建模假设）：寿命作为优化目标 Y；约束 MIN_LIFE=10 年，寿命上限 LIFE_CAP=50 年，建议论文基准 Y0=20 年。公式 Y = (w − t_req − 腐蚀余量)/v_corr，其中 w 为壁厚、t_req 为承压所需壁厚。

### 5. 统一传热核心公式（已定版本，2026-08-13 与代码口径一致）

1. 牛顿冷却：Q = h·A·ΔT，ΔT = T_s − T∞。
2. 水平圆柱自然对流（Churchill-Chu，Ra 适用域约 10⁻⁵–10¹²）：
   Gr = g·β·(T_s−T∞)·D³/ν²，Ra = Gr·Pr，
   Nu = {0.60 + 0.387·Ra^{1/6}/[1+(0.559/Pr)^{9/16}]^{8/27}}²，
   h = Nu·k/D。
3. 直矩形翅（绝热翅尖）：m = √(2h/(k_f·t_f))，η_f = tanh(m·H_f)/(m·H_f)；
   A_f = (2H_f + t_f)·L（单根，含两侧+翅尖），
   A_eff = A_base + η_f·N_f·A_f。
4. 耐压壁厚：P = ρ_sea·g·H；[σ] = min(Rm/2.7, ReL/1.5)（GB/T 150.1-2024）；
   δ_min ≥ P·D/(2[σ])；轴压稳定校核安全系数 2.0。
5. 腐蚀寿命：Y = (w − δ_min − 腐蚀余量)/v_corr，Y ≤ LIFE_CAP=50，约束 Y ≥ MIN_LIFE=10。
6. 成本：C_材料 = Σ(ρ_i·V_i·p_i)；C_涂层 = A_涂层·150 元/m²；
   C_总 = C_材料 + C_涂层（可选再乘加工/采购系数 k=2.0，见 3.5）。
7. 问题4 动态方程（集总参数）：m_shell·cp·dT/dt = Q_gen − h(t)·A·(T − T∞(t))；
   RK4：k1=f(t,T)，k2=f(t+Δt/2,T+Δt·k1/2)，k3=f(t+Δt/2,T+Δt·k2/2)，k4=f(t+Δt,T+Δt·k3)，
   T(t+Δt)=T+Δt·(k1+2k2+2k3+k4)/6，建议 Δt=3600 s。
8. 时间序列插值：T∞(t)=Tm+A·cos(2π(t−t_peak)/8760)；u(t) 由月均 u/v 分段线性插值；
   潮位 h_tide(t)=Z0+ΣA_i·cos(2π(t−t0)/T_i−g_i)。
